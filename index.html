Check a link for potential security risks before opening it.

TrustURL examines the link text in your browser and, when enabled, asks a reputation service whether the address is on a known-threat list. It never opens the link. How your link is handled

How it works

  1. Paste a link

    Copy the address from a message, email or page without opening it.

  2. Run the security checks

    TrustURL inspects the structure of the address and checks it against a reputation service when one is configured.

  3. Review the findings

    Read what was found, how it was found, and what was not checked before you decide what to do.
